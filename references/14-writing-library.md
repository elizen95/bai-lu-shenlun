# 大作文参考库

## 来源与内容边界

用户提供的2015—2025年度中指看报、20260527文件、申论目录均已保存可提取全文。文章表按日期式标题自动分段，提供单篇检索。未形成独立文章卡片的内容仍保留在来源全文中。

中指提示为编辑的教学分析。正文中括号批注也可能来自整理者，不能当作人民日报原文或作者原话。文章卡片显示原文件ID、原日期标签、报刊署名行和原文片段位置。文件名与文内日期不一致时同时保留，以实际署名行核对发表时间。

## 检索和使用

```text
python scripts/library.py search "乡村" --kind article --theme 乡村振兴 --limit 5
python scripts/library.py search "传统文化" --kind article --limit 5
python scripts/library.py show A-012-001 --length 14000
python scripts/library.py search "论证" --course C12
```

先确定本题需要的功能，再选文章。可按开头、释义、关系分析、机制论证、例证、对策、过渡和结尾提取片段。每次输出材料卡应包含主题、来源及日期、原句或转述、适用场景、与当前论点的连接、改写示例。缺精确出处时明确待核。

## 三种训练

- 拆解训练。标出中心判断、分论点、论据、分析和回扣，解释段落如何支持中心。
- 仿写训练。抽出论证关系，换用当前题目的材料完成一段，比较哪些表达能保留。
- 迁移训练。同一素材分别服务于两个不同论点，说明适用条件，剔除不贴切的部分。

用户明确要范文时结合题干与材料写作，并标明教练参考文。年度美文作为论证与表达参考，不能替代小题给定材料中的要点，也不能用旧文预测今年必考。
