# 批改与评分校准

## 建立评分依据

先取得完整题干、材料、分值、字数限制和学员原答。优先用同一道题的原版课程批改标准。C02-018、022、025、028、031、073、077、081提供逐题尺度，部分允许近义替换、拆并变化，也含课堂提示性扣分与封顶。专项课C03-080有做题痕迹与参考答案。

参考答案与官方标准分别标识。有课程标准时注明“按白鹭课程标准进行训练评分”。若该标准含训练性规则，给内容覆盖结果，并单列课堂规则的影响。学员要求严格按课程标准时可计算训练分，仍须标清性质。

没有逐题尺度时，从题干和材料提炼教学核对表，并标为教练拟定。可给估分区间及不确定原因，禁止使用“覆盖80%即满分、40%即半分”等通用阈值。题目满分未知时先做定性诊断。

## 小题核对

为每个要点建立下列记录。

| 核对项 | 内容 |
|---|---|
| 材料依据 | 资料号、段落或具体原句 |
| 要点含义 | 必须表达的主体、行为、对象、结果或限定 |
| 可接受表达 | 原标准允许的近义与等义表述 |
| 学员证据 | 原答中的具体句子 |
| 覆盖判断 | 完整、部分、缺失、含义相反或无法确认 |
| 赋分依据 | 原标准的分值与条件，或明确标出的教学估计 |

同一含义避免重复计分。分点数量与采分子项数分开统计。合理近义表达按含义评价，材料专业名词与限定词遗漏导致含义变化时具体指出。格式、字数、错字与卷面依据题目要求和可获得标准处理。拍照不清的文字标为待确认，不能当作学员写错。

## 大作文

先核立意与题干对应，再检查分论点关系、论据和分析、结构完整、材料运用、语言与字数。用户资料与机构范文不提供全国统一档线。满分40分、35分等分别按本题尺度估计，说明是教学估分。

给出导致判断的具体段句。不能因为使用某种开头、未写三分论点、未逐字背口诀而直接降档。高质量并列结构与递进结构都结合任务判断。

## 反馈结构

默认给出评分依据与估分，随后列主要命中点、关键遗漏或逻辑问题，提供1—2处针对性改写，最后安排一个可完成的重写任务。详细批改时追加逐点表，学员已要完整范文时给出符合字数的参考答案，并说明另一种可行组织方式。

## 失分归因

| 编号 | 可观察问题 | 对应训练 |
|---|---|---|
| E1 | 范围、主体、对象或问法判断错误 | 题干任务陈述 |
| E2 | 材料相关要点遗漏 | 段落与要点对照 |
| E3 | 把例子、背景当要点或曲解含义 | 总分辨认与等义核验 |
| E4 | 过度合并或零散重复影响内容 | 逐点解释合并理由 |
| E5 | 概括表达不能涵盖具体内容 | 原词、上位词与等义提炼比较 |
| E6 | 字数分配失控 | 按重点压缩与格数预算 |
| E7 | 分析顺序或语义关系断裂 | 解释、证据、判断连线 |
| E8 | 多对象或多要素对应错误 | 对照表配对 |
| E9 | 对策缺乏针对性、细节或可行性 | 问题、原因、措施链 |
| E10 | 应用文用途、受众或必要格式不符 | 身份与任务改写 |
| E11 | 作文论题或立意偏离 | 题干约束逐项核对 |
| E12 | 分论点交叉、重复或支撑不足 | 两套提纲比较 |
| E13 | 结构不完整或时间失控 | 限时提纲与成文 |
| E14 | 案例堆砌、论证缺少机制解释 | 案例后补两句分析 |
| E15 | 表达不准确或影响理解的语言错误 | 保义压缩与替换 |
| E16 | 素材迁移不当、引文或事实失实 | 溯源核验与适用边界 |

只记录有原答证据的问题，不要求每篇凑齐类别。同题重写改善单列，跨题独立表现才用于判断迁移。复发与训练安排见 [13-learner.md](13-learner.md)。
