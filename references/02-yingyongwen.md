# 应用文与贯彻执行

主要依据为C01-039—040、C01-001第11—13页，强化课C02-007—008、C02-076、C02-080，专项课C03-029与相关板书。

## 先锁定真实任务

确认谁写、写给谁、写什么、为何写、依据哪些材料、有什么格式与语言要求。题干明确给定标题时照用。自拟标题优先保留题干主题与文体，避免换掉任务名称。

把应用文看作有身份和用途的材料加工。经验交流多总结做法，情况汇报可能兼有成绩、问题和建议，宣传稿可能兼有人物事迹、精神与号召。文体提供倾向，题干与材料决定主体内容。

## 用五把钥匙组织层次

| 课堂方法 | 可执行动作 |
|---|---|
| 讲逻辑 | 按是什么、为什么、怎么办安排已有内容 |
| 讲顺序 | 依时间或工作阶段组织 |
| 讲过渡 | 识别材料中的承启关系，连接前后板块 |
| 讲故事 | 以背景、经过或主要做法、结果组织 |
| 讲规矩 | 题干指定几个部分，就逐项回应 |

题干明确的结构先落实。以做法为主且结构清楚时，可用背景加若干做法段。背景并非每题必需，不能把“一加N”强加给所有文种。编者按通常紧凑成段，其他任务结合篇幅与用途分段。

做法段可采用前置概括加具体内容。作用、条件、背景等部分按自身逻辑表达，无需句句强做概括词。提纲可列要点，完整讲话稿须有必要串联，语言做到通顺、受众明确。

## 格式和语言

依题干要求处理标题、称呼、发文主体和日期。课堂通常强调标题，并按文种补充其余要素。新闻报道、短评、编者按和汇报提纲不能统一补上书信式称呼与落款。题干写“不考虑格式”时，区分课程标题建议与该题评分依据，不能无据认定缺标题必扣分。

语言得体体现身份、场合与受众。号召性任务在结尾结合行动目标发出倡议，介绍性任务说明所介绍的对象与目的。题目要求提纲时优先简练，要求生动时通过具体事迹、贴切表达增强感染力。

## 训练和批改

先让学员给出身份、用途、内容板块及各板块材料依据，再成文。核对内容覆盖、板块顺序、任务目的、必要格式和表达。具体可比范本为强化课C02-077新闻宣传稿与编者按批改标准，C02-081工作交流提纲与案例摘要标准。它们的赋分安排只用于对应题目。
