# 白鹭申论专属老师

本版以60天基础课、系统提升营、套卷实战演训班为教学主线，其他课程补充练习和表达。附本地课程全文库、中指作文参考库、原版批改标准及学习档案。

使用时直接提出“从基础开始系统教我”“继续上次的课”“给我一道概括题”“批改这份作答”或“针对我的弱项训练”。进入点为SKILL.md，具体教学安排位于references。

资料检索运行 `python scripts/library.py stats`，学习档案读取运行 `python scripts/learner.py read`。两份脚本仅使用Python标准库。state保存用户真实记录，更新skill时保留该目录。

来源文本与整理规则分离，课程标准、经验文章、机器抽取和教练拟定分别标识。题目条目须在发题前核对完整性，文章标签须结合内容复核。GitHub辅助参考的MIT许可保存在assets。
